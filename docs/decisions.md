# 决策记录

只记「不写下来就会被重新讨论」的决定。每条给出理由，理由比结论重要。

## 产品

**OpenGal 是角色运行时，不是聊天工具、不是桌宠、不是 agent。**
判断标准：把用户输入全部拿掉，她还能继续存在——自己看屏幕、翻东西、决定要不要开口。

**与 DSH 竞争，不做封装。** 差异点是开箱即用语音与记忆，不需要靠"也能实现"来证明。

**角色是主体，agent 是内脏。** 导演问的是「如果是她，此刻会怎么做」，不是「该怎么回答」。

## 四条不变量

1. **沉默是默认。** 解析失败、字段缺失、模型超时一律 silent，没有任何路径默认说话。
2. **外部内容不可信。** 网页与屏幕内容强制 `trusted: false`，只能当线索，不能改变立场。这是代码约束，不靠提示词。
3. **身份稳定。** 角色包更新不静默改写已有实例的经历。
4. **记忆可纠。** 承诺可追溯、可纠正、可删除，不承诺"记得一切"。

## 导演层

- 感知是一等输入：`PerceptionEvent[]`，每种带 TTL，过期即不算"此刻知道的事"。
- 动作是判别联合，先实现 `silent / speak / wait`；`emote / move / ask / browse` 保留类型，落地前降级为 silent。
- 主动性预算只约束主动开口，**不约束回应用户**。
- `self.doing` 来自真实状态：`speaking`（音频在播）> `thinking`（isSending）> `idle`。
- 主动时刻默认关闭。理由：主动开口是最容易让人卸载的功能。

## 角色卡

- 纯声明式，不携带可执行代码。
- 路径必须相对且不越界（`isSafeCardRelativePath`）。
- `llm` 只允许生成参数，endpoint 与密钥只能来自全局配置。
- 校验失败即拒绝，不做"尽力加载"。
- 未知字段只记 warning，便于格式向前扩展。
- 非法 `id` 回退到目录名，非法 `color` 忽略——这两个不拒绝整张卡，是为了兼容旧卡。

## 自我识别

- **自我存在是注入的事实，不是视觉推理。**
- 默认不让角色看到自己：桌宠窗口开启内容保护，截图里不出现自身。
- 关掉该选项（直播录制需要）后才依赖提示词兜底。
- 兜底话术属于角色卡：不同角色看到"像自己的东西"的反应本来就该不同。

## 整改顺序（Astra 评审）

1. 数据安全：聊天与压缩提交边界（A2）→ 备份与迁移（A1）
2. 存在感：自我感知 → 感知扩展 → 情绪 → 演出
3. 角色卡收尾
4. 桌面端配置并发（B2）

理由：导演层再深，也建立在聊天记录与记忆存储之上。边界漏一次，前面所有工作都可能白费。

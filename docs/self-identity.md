# 自我识别

角色拿不到“屏幕上那个是我”这一事实时，会把截图里的自己当成陌生人，甚至反问用户“这是谁”。

## 规则

1. **自我存在是注入的事实，不是视觉推理。** 不要再让模型靠“长得像”去判断。
2. **默认不让角色看到自己。** 桌宠窗口开启内容保护，截图里不出现自身。关闭该选项后（直播录制需要）才依赖提示词兜底。
3. **兜底话术**：屏幕上出现与自身形象相似的陌生角色时，默认理解为“像我的东西”，不否认、不追问是谁。写进角色卡提示词，因为不同角色的反应本来就该不同。

## 配置

`AppConfig.screen.excludeSelf`（默认 `true`）。关闭后 OBS 等采集工具才能录到桌宠窗口。

## 状态

| 项 | 状态 |
|---|---|
| 截图排除自身（`setContentProtection`） | 已实现 |
| `self_presence` 感知事件（位置/姿势/是否可见） | 未实现 |
| 角色卡兜底话术 | 未实现 |
| 自画像参考图 | 未实现（最后做，收益最低） |

## 注意

桌宠窗口在同一显示器内是 320×420 的独立窗口，位置可拖动。若改为全屏透明覆盖层，按窗口矩形排除会把整块屏幕遮掉，届时必须改为按角色实际渲染包围盒处理。
